# Oathkeep Code of Conduct

## Our Standards

Oathkeep is an open-source technical community dedicated to clean-room systems engineering, GPU translation, and Xbox Series X|S interoperability on Windows.

Expected behavior:
- Keep discussions technical, constructive, and respectful.
- Strictly follow [docs/asset-policy.md](docs/asset-policy.md) across GitHub and Discord.
- Give proper credit to upstream authors and fellow contributors.

Zero-tolerance violations (immediate removal/ban):
- Requesting, linking, sharing, or discussing how to obtain copyrighted software, dumps, keys, or extracted assets.
- Uploading copyrighted binaries, shaders, screenshots of proprietary assets, or decompiled code to GitHub or Discord.
- Harassment, hate speech, doxxing, spam, or malicious links.
